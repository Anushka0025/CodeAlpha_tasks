# Car Price Prediction using Machine Learning 🚗

## 📌 Project Overview

This project focuses on predicting the selling price of used cars using Machine Learning techniques. The objective is to analyze various factors such as the car's manufacturing year, present price, fuel type, transmission type, ownership history, and kilometers driven to estimate its selling price accurately.

This project is developed as a part of the **CodeAlpha Internship Program** to demonstrate skills in data preprocessing, exploratory data analysis (EDA), feature engineering, machine learning, and predictive modeling using Python.

---

## 🎯 Objective

- To analyze the car price dataset and identify important patterns.
- To perform data cleaning and preprocessing.
- To understand the relationship between different car features and selling price.
- To build a machine learning model for predicting car prices.
- To evaluate the model using regression performance metrics.
- To predict the selling price of used cars accurately.

---

## 📂 Dataset

The project uses a used car dataset containing various features that influence the selling price of a car.

The dataset includes:

- Car Name
- Year
- Selling Price
- Present Price
- Kms Driven
- Fuel Type
- Selling Type
- Transmission
- Owner

The dataset is used to train and evaluate a machine learning regression model for predicting car prices.

---

## 🔄 Machine Learning Workflow

The workflow followed in this project includes:

- Importing required Python libraries.
- Loading and understanding the dataset.
- Performing data cleaning and preprocessing.
- Encoding categorical variables.
- Conducting exploratory data analysis (EDA).
- Splitting the dataset into training and testing sets.
- Training the machine learning model.
- Evaluating model performance.
- Predicting car selling prices using the trained model.

---

## 🤖 Model Used

The following Machine Learning model is used in this project:

- Random Forest Regressor

Random Forest Regressor is an ensemble learning algorithm that combines multiple decision trees to improve prediction accuracy and reduce overfitting.

---

## 📈 Evaluation Metrics

The model performance is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score (Coefficient of Determination)

These metrics help measure the accuracy and effectiveness of the prediction model.

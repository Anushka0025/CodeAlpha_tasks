# Sales Prediction using Python 📈

## 📌 Project Overview

This project focuses on predicting product sales using Python and Machine Learning techniques. The objective is to analyze the relationship between advertising expenditures and product sales, build a predictive model, and estimate future sales based on advertising budgets.

This project is developed as a part of the **CodeAlpha Internship Program** to demonstrate skills in data preprocessing, exploratory data analysis (EDA), machine learning, and predictive modeling using Python.

---

## 🎯 Objective

- To analyze the sales dataset and identify important patterns.
- To perform data cleaning and preprocessing.
- To understand the relationship between advertising budgets and sales.
- To build a machine learning model for sales prediction.
- To evaluate the model's performance using regression metrics.
- To predict future sales based on advertising expenses.

---

## 🛠️ Technology Used

- 🐍 Python
- 📓 Jupyter Notebook
- 🐼 Pandas
- 🔢 NumPy
- 📊 Matplotlib
- 🎨 Seaborn
- 🤖 Scikit-learn

---

## 📂 Dataset

The project uses a sales dataset containing advertising expenditure across different media platforms and corresponding product sales.

The dataset consists of features such as:

- TV Advertising Budget
- Radio Advertising Budget
- Newspaper Advertising Budget
- Sales

The dataset is used to train and evaluate a machine learning regression model for predicting sales.

---

## 🔄 Machine Learning Workflow

The workflow followed in this project includes:

- Importing required Python libraries.
- Loading and understanding the dataset.
- Performing data cleaning and preprocessing.
- Conducting exploratory data analysis (EDA).
- Splitting the dataset into training and testing sets.
- Training the machine learning model.
- Evaluating model performance.
- Predicting sales using the trained model.

---

## 🤖 Model Used

The following Machine Learning model is used in this project:

- Linear Regression

Linear Regression is a supervised machine learning algorithm used to predict continuous values by finding the relationship between independent variables and the target variable.

---

## 📈 Evaluation Metrics

The model performance is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score (Coefficient of Determination)

These metrics help measure the accuracy and effectiveness of the prediction model.

## Projects Overview

### 🌸 Iris Flower Classification

A Machine Learning classification project that predicts iris flower species based on flower features using classification algorithms.

**Libraries Used:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.

---

### 📊 Unemployment Analysis using Python

A data analysis project that explores unemployment trends using data cleaning, visualization, and statistical analysis.

**Libraries Used:** Python, Pandas, NumPy, Matplotlib, Seaborn.

---

### 🚗 Car Price Prediction using Machine Learning

A regression-based Machine Learning project that predicts car prices using different vehicle features.

**Libraries Used:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.

---

### 📈 Sales Prediction using Python

A predictive analysis project that estimates sales values using historical data and regression techniques.

**Libraries Used:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.
